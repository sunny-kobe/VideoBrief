# VideoBrief 自助生产闭环说明

VideoBrief 从 Creative Brief 开始，而不是从一段待摘要的视频开始。

当前本地流程包含：

1. 创建独立项目并填写目标、受众、画幅和核心观点；
2. 导入自有或已确认可用的视频、音频、图片、Markdown 和文本；
3. 将来源、核验状态、权利状态和处理结果保存在同一份 project.json；
4. 用户确认脚本、场景和候选画面后运行 FFmpeg；
5. proof 检查项目指纹、成片、音轨、字幕和多个画面时间点；
6. 导出完整生产包，但不自动发布。

本文件由 VideoBrief 仓库自身维护，可用于本地 dogfood。它只描述当前仓库实现，不证明市场需求。
