# 海外 AI 信息再制生产台路线图

## 1. 项目定义

当前项目不再定义为“AI 视频研究笔记产品”，而是定义为：

> 面向自营国内内容账号的海外 AI 信息再制生产台。

它的任务是把海外 AI / 编程 / Agent / GitHub / 工作流相关信号，经过筛选、核验、中文语境解释和内容包装，输出为国内平台可发布的短视频、图文卡片、公众号/飞书周报和资料包。

## 2. 最高优先级

最高优先级只有一个：

**稳定生产可发布、可复盘、可复用的海外 AI 信息内容包。**

当前 v1 只做一种模板：

**单信号 AI 工具/项目解读：一条可核验事实 + 一手官方画面 + 中文判断 + 实际验证建议。**

多信号周报等 v1 的来源、分镜、渲染和验收闭环稳定后再扩展。

第一阶段不要把精力放到：

- 登录、订阅、额度、Stripe、Supabase。
- 公开视频转写和研究笔记结果页。
- 自动抓取全网热点。
- 做成通用 SaaS。
- 批量矩阵分发。

## 3. 一句话口径

推荐对外口径：

**帮中文 AI 实践者快速看懂海外 AI 新项目、新论文、新工作流和新工具，判断哪些值得关注、值得试、值得收藏。**

内部工作口径：

**海外信号筛选 + 来源核验 + 中文再制 + 平台化输出 + 反馈复盘。**

## 4. 目标受众

第一阶段只服务一类核心读者：

**中文 AI 实践者 / 开发者 / 独立开发者 / 产品人 / AI 工作者。**

他们关心：

- 最近海外有什么新 AI 项目或新工具。
- 是否真的有用，而不是营销热。
- 怎么试、适合谁、不适合谁。
- 能否沉淀成自己的工作流、模板、脚本或素材。

## 5. 核心输入

每个信号至少包含：

```text
title: 标题
source_url: 原始链接
source_type: official | github | paper | demo | social | video | news
published_at: 发布时间
claim: 一句话事实
why_it_matters: 为什么值得关注
china_context: 对中文用户有什么关系
risk_note: 风险或不确定点
clip_reference: 可选，视频片段时间戳或截图说明
```

优先来源：

- 官方博客 / Release / 文档。
- GitHub repo、issue、PR、demo。
- arXiv / 论文主页 / 项目页。
- 作者 X / HN / Reddit 讨论。
- YouTube / demo 视频片段。
- Newsletter 或新闻只作为辅助，不当成唯一事实来源。

## 6. 核心输出

每个信号生成一组内容包：

```text
hook: 3 秒开头钩子
short_summary: 3-5 条中文要点
voiceover_script: 60-90 秒中文旁白
subtitle_script: 中文字幕文案
shot_list: 分镜和画面建议
xiaohongshu_cards: 3-6 张图文卡片文案
wechat_paragraph: 公众号/飞书周报段落
source_links: 原始链接清单
uncertainty_notes: 不确定和待验证点
```

## 7. 生产流程

```text
1. Project / Source Intake
   为一条候选信号建立项目，登记一手链接、本地素材和目标受众。

2. Source Check
   保留有一手来源或可交叉核验的信号。

3. Editorial Judgment
   判断是否值得中文用户关注：新不新、能不能试、有无行动价值、是否可沉淀。

4. Transcript / Clip Candidates
   生成转录稿和候选片段；系统给出推荐，人工选择最终画面。

5. Scene / Voice Edit
   把场景绑定到来源片段，逐句检查标题、字幕和中文旁白。

6. Render / Current-output QA
   用 FFmpeg 渲染，并按当前项目 manifest 检查指纹、画面、音轨和全部产物。

7. Publish
   先选 1-2 个平台发布，不同平台重写标题和封面。

8. Feedback Ledger
   记录播放以外的真实反馈：收藏、评论、私信、下载、加好友、付费意向。

9. Assetize
   把表现好的模板沉淀成脚本模板、选题评分表、资料包或服务流程。
```

## 8. 第一阶段 MVP

第一阶段做内部工具，不做公开产品。

### 页面 / 模块

1. **信号列表**
   - 标题、来源、可信度、主题、状态。
2. **信号详情**
   - 事实、来源、截图/片段、风险说明。
3. **内容包预览**
   - 短视频脚本、字幕、旁白、小红书卡片、周报段落。
4. **来源清单**
   - 可复制原始链接和引用说明。
5. **反馈记录**
   - 平台、发布时间、收藏、评论、私信、资料领取、付费意向。

### 第一批样例

先连续完成 3-5 条单信号解读样例，再判断是否扩展多信号周报。例如：

- Claude / Anthropic 新产品或实验。
- ComfyUI / MCP / Agent 工作流。
- Meta / Google / 开源研究项目。
- GitHub 新项目。
- AI 图像、视频、CAD、机器人、脑机接口等高信息差方向。

## 9. 内容模板

### 60-90 秒短视频

```text
0-3 秒：钩子，讲清楚这周最值得看的变化。
3-8 秒：来源和范围，本期来自官方、GitHub、论文和 demo。
8-60 秒：逐条快速盘点，每条用“是什么 + 为什么重要”。
60-80 秒：给出判断，哪些值得试，哪些只是热闹。
80-90 秒：引导评论关键词或领取完整来源清单。
```

### 单条信号口播

```text
这个项目叫 {{name}}。
它解决的是 {{problem}}。
最值得关注的是 {{key_change}}。
对中文用户来说，它可能影响 {{china_context}}。
但现在还要注意 {{risk_note}}。
原始链接我放在完整清单里。
```

### 小红书卡片

```text
封面：这周海外 AI 圈最值得看的 {{count}} 件事
卡 1：一句话结论
卡 2-5：每条信号是什么、为什么重要
卡 6：哪些值得试、哪些先观望
末页：评论关键词领取来源清单 / 完整周报
```

## 10. 验证指标

继续投入的信号：

- 收藏率明显高于账号均值。
- 有用户评论问“链接 / 怎么试 / 有没有教程”。
- 有私信要完整清单、资料包或工作流。
- 同一模板能连续复用 3 次以上。
- 出现付费资料包、服务或社群意向。

止损信号：

- 只有播放，没有收藏、评论、私信或下载。
- 每期生产时间过长，无法模板化。
- 必须依赖搬运原片段或夸张标题才有流量。
- 内容只像新闻播报，没有判断、链接、方法或资产沉淀。

## 11. 合规边界

- 不完整搬运海外视频，不默认下载、缓存或分发原始音视频。
- 视频片段只作为必要引用或演示素材，优先保留来源和上下文。
- AI 生成、合成配音、合成画面按平台要求标识。
- 不伪造测试、不伪造首发、不伪造用户反馈。
- 医疗、法律、金融投资等高风险内容只做信息说明，不给决策建议。

## 12. 近期执行顺序

1. 建立 `weekly-ai-signals` 样例数据。
2. 设计内容包 TypeScript 类型。
3. 把旧结果页改造成内部内容包预览页。
4. 做第 1 期“一周 AI 大事”脚本和图文卡片。
5. 用真实账号发布，记录反馈。
6. 根据反馈决定继续周报、单条深挖、资料包还是停止。
