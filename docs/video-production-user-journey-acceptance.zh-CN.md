# VideoBrief 首次用户路径验收

日期：2026-07-12

## 验收目标

从隔离的全新浏览器窗口，以没有项目背景知识的首次用户身份，完成：创建项目、填写 Creative Brief、导入本地自有素材、审核来源事实、生成并确认原创脚本、确认画面、校对旁白字幕、渲染、技术验收和下载产物。

本次真实项目：`video-project-1783855221061`（首次用户完整路径验收）。

## 首轮发现

1. 项目列表和工作台暴露 `cleared`、`sources/scenes`、candidate ID、绝对路径等内部词，用户无法判断下一步。
2. 创建页一次展示过多字段，没有必要项与高级设置的层次。
3. 导入素材后缺少明确下一步；空项目仍展示无效预览和渲染动作。
4. 原步骤顺序不符合实际制作顺序；资料审核页一次平铺全部事实和疑问，页面过长。
5. AI 返回的来源引用不完整时，页面直接暴露英文结构校验错误。
6. 脚本页会把导入占位场景误当成已生成脚本，缺少明确的生成、确认和应用动作。
7. 画面步骤只有候选状态，没有“确认使用当前画面”，用户的最终选片决定没有闭环。
8. 字幕步骤只能编辑字幕，无法在同一步校对实际用于 TTS 的旁白。
9. 导出页在渲染前列出大量缺失文件和内部路径，四类状态也直接显示英文枚举。

## 已完成优化

- 主流程统一为 `素材 → 审核 → 脚本 → 画面 → 字幕 → 导出`，每一步只展示当前主要任务和下一步。
- 创建页首屏只保留四项必要输入，其余输出限制放入高级设置；项目 ID 可自动生成。
- 素材导入、逐来源审核、脚本确认、选片确认、字幕校对和导出均增加明确的继续动作。
- 审核页按当前素材显示事实和疑问，并保留来源定位、权利状态和人工确认。
- AI 结果强制每条事实和疑问包含来源引用；可修正错误和额度错误转为中文操作提示。
- 相同内容哈希的已完成来源可以本地复用解析，但重新映射所有 source/fact/transcript/uncertainty ID，事实回到待确认状态。
- 修改画面素材或时间段会撤销旧选片确认；所有启用场景未确认前不能进入字幕或导出。
- 旁白与屏幕字幕可在同一步逐段编辑，TTS 试听使用旁白字段。
- 导出页主区域只保留状态检查、渲染动作和真实可下载产物；完整路径、缺失文件和制作记录进入折叠技术区。
- 四类状态保持独立，但用户界面改为中文：技术状态、素材权利、发布状态、市场验证。

## 第二轮与第三轮验证

- 第二个隔离浏览器窗口创建 `video-project-1783855221061`，导入自有 Markdown 和 PNG，2/2 来源处理完成，12 条事实逐来源人工确认。
- 使用真实模型生成并明确应用原创 narrative 和 1 个场景；人工确认当前图片画面后，选片 ID 写入 canonical `project.json`。
- 浏览器触发渲染，render job 完成；MP4、SRT、ASS、配音、timeline、封面、来源清单、project snapshot、render/export manifest 和 ZIP 均实际存在。
- 成片为 45 秒、1080x1920、30fps、H.264 + AAC 48kHz；FFmpeg 完整解码通过，五张 proof frame 非空，字幕已烧录。
- render manifest 与 export manifest 均为 `proof.passed=true`、`rightsCheck.passed=true`、issues 为空，项目 fingerprint 一致。
- 第三个隔离浏览器窗口无显式 `view` 打开项目后自动进入导出步骤；桌面和 390x844 移动布局无控件遮挡或横向溢出。
- 工作台预览和全屏播放器在桌面、移动均显示真实非空画面；控制台只有开发模式 HMR 信息，没有应用错误。

## 当前结论

- Phase 3 Gate：通过。用户能看到来源依据和不确定项，事实由用户确认，AI 草案不会无提示覆盖场景。
- Phase 4 Gate：通过。候选选择持久化，人工选片是显式动作，渲染进度、失败状态、技术 proof 和完整导出包已闭环。
- Phase 5 Gate：未通过。当前只有一个项目按优化后的完整路径关闭；仍需再完成 2–4 个不同题材 dogfood。

## 剩余风险

- 本次成片使用一张自有工作台截图持续 45 秒，足以证明流程、字幕、音轨和导出契约，但不代表生产级叙事节奏或画面质量。
- 本地来源解析复用依赖相同内容哈希和已完成来源；首次出现的新素材仍依赖本地 Whisper 或已配置的模型端点。
- 当前配音仍是 macOS 系统音色；更自然配音属于后续质量提升，不阻塞本地闭环。
- 未执行发布，`publication_status` 保持未发布草稿；没有外部反馈，`market_status` 保持 none。
